🔑 Authentication & Login Screen
All Users ▼

Objective: Secure login and registration using phone OTP verification or Google credentials, synced to PostgreSQL database via Firebase tokens.

Step-by-Step Flowchart
Frontend (Mobile)
Enter Phone No
➔
Enter 6-Digit SMS OTP
➔
Firebase returns ID Token
↓ (Forward HTTP Post)
Backend (API)
Verify with Firebase Admin SDK
➔
Look up or Create User in PostgreSQL
➔
Generate & Return Profile JSON
Technical Specifications
  • OTP Code Resending: Renders countdown lock timer on Phone Screen to prevent multiple SMS requests.
  • Authorization Token: The Firebase ID token is saved securely and attached as Authorization: Bearer Token in every HTTP request header.
  • Auth Entry Points: app/(auth)/login.tsx, src/context/AuthContext.tsx.

⚙️ Moderation Actions Settings Sheet
Author / Admins / Mods ▼

Objective: Moderation actions sliding up from the bottom (Pin/Unpin notices, Soft Deleting notices) with proper roles gatekeeping.

Step-by-Step Flowchart
Role Check
Tap Ellipsis settings trigger
➔
Is Admin/Mod or Post Author?
➔
Open sliding bottom sheet
↓ (Action Dispatch)
Moderation
Pin (Admins/Mods) or Delete (Admins/Author)
➔
Set activeAction loading state
➔

Technical Specifications
  • Granular Loading States: Employs an activeAction: 'pin' | 'delete' | null state so only the clicked button activates a loading indicator, keeping the other action button disabled to block concurrent triggers.
  • Soft Deletes: Backend flags is_deleted = true, retaining PostgreSQL audit trails and preserving Supabase images.
  • Drawer Entry Points: app/(tabs)/index.tsx, Backend softDelete: PATCH /announcements/:id/soft-delete.

🏏 Sports Hub: Cricket Onboarding & Feed
All Users ▼

Objective: Build a premium sports section starting with Cricket Player Profiles, featuring a multi-step registration wizard, personal player cards, and a paginated list of all community players.

Step-by-Step Flowchart
Onboarding Wizard
1. Choose Role
➔
2. Set Style Form
➔
3. Card Preview
➔
POST /players/me
↓ (Sync Store & Redirect)
Player Feed View
Render user profile card
➔
GET /players (Paginated)
➔
Render player list feed
Technical Specifications
  • Verification & Sync: App queries GET /sports/cricket/players/me on mount to dynamically update Zustand local caching store (`registrations`). If 404 is returned, it handles it gracefully.
  • Opt-In Overlay: Renders SportsOptIn.tsx with circular icons, highlights, and buttons. "Just Browsing" sets seenOptIn to true.
  • Onboarding wizard stack:
    • Step 1 (role.tsx): Interactive spring-animated role cards (batsman, bowler, allrounder, keeper).
    • Step 2 (style.tsx): Batting and bowling details with dynamic layouts (bowlers must bowl; batsmen can select "I don't bowl" to hide bowling type options with ease-out layout animations).
    • Step 3 (preview.tsx): Preview of the premium player card + Axios profile post submittal.
  • Premium Player Card: Styled with expo-linear-gradient, watermark bat, avatar, role badges, style rows, and static/placeholder stats grid.
  • Community List & Pagination: Renders paginated listings (`GET /sports/cricket/players?page=N`) via infinite scrolling FlatList and RefreshControl.
  • Next Steps (Phase 2): Teams registration & squad roster requests, upcoming match fixtures calendars, and MVP standings leaderboard calculators.
  • Entry Points: app/(tabs)/sports.tsx, app/sports/cricket/onboarding/.
