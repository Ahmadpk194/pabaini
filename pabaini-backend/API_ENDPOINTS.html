POST /api/v1/auth/login Public

Authenticates users via a Firebase ID token. Registers them dynamically in the PostgreSQL database if signing in for the first time. Pre-fills Gmail users' name and profile picture.

Headers
  • Content-Type: application/json
Request Body (JSON)
{
  "id_token": "YOUR_FIREBASE_ID_TOKEN"
}
Response (JSON)
{
  "success": true,
  "status": 201,
  "message": "Login successful",
  "data": {
    "user": {
      "id": 1,
      "firebase_uid": "C0Np3cHX2ugOWNzenBka4O8zokt1",
      "phone": null,
      "email": "user@gmail.com",
      "name": "User Name",
      "avatar_url": "https://...",
      "village": null,
      "is_diaspora": false,
      "role": "resident",
      "created_at": "2026-06-12T01:10:00.000Z",
      "updated_at": "2026-06-12T01:10:00.000Z"
    }
  }
}

GET /api/v1/announcements Public

Fetches all announcements ordered by newest first with pagination and optional category filtering.

Query Parameters
  • page (optional): Page number (default: 1)
  • limit (optional): Items per page (default: 10)
  • category (optional): Filter by category (values: general, urgent, event, jirga_decision)

PATCH /api/v1/announcements/:id/soft-delete Protected

Soft deletes an announcement. Only the author or admins/moderators can delete. This is a soft delete - the announcement is marked as deleted but remains in the database for audit purposes. The image is NOT deleted to allow for recovery.

Headers
  • Authorization: Bearer <YOUR_FIREBASE_ID_TOKEN>
Response (JSON)
{
  "success": true,
  "status": 200,
  "message": "Announcement deleted successfully",
  "data": null
}
DELETE /api/v1/announcements/:id Admin Only

Hard deletes an announcement. Only admins can permanently delete. This permanently removes the announcement from the database and deletes its image from Supabase Storage.

Headers
  • Authorization: Bearer <YOUR_FIREBASE_ID_TOKEN>
Response (JSON)
{
  "success": true,
  "status": 200,
  "message": "Announcement permanently deleted",
  "data": null
}
