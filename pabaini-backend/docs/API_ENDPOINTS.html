POST /api/v1/auth/login Public

Validates Firebase ID token signature. Automatically registers the user profile in PostgreSQL database if logging in for the first time.

Headers
  • Content-Type: application/json
Request Inputs
Field Type Required Description
id_token string Yes FCM auth token payload passed from client verification.
Request Body Example (JSON) 
{
  "id_token": "YOUR_FIREBASE_ID_TOKEN"
}
Request Client Snippet (cURL / Axios) 
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"id_token": "YOUR_FIREBASE_ID_TOKEN"}'
axios.post('http://localhost:3000/api/v1/auth/login', {
  id_token: 'YOUR_FIREBASE_ID_TOKEN'
});

Soft deletes a notice by setting `is_deleted = true`. Image uploads are retained in Supabase storage to support administrative audit recovery. Moderators are restricted from soft-deleting other people's posts.
